# 配置字段说明

配置就是一份 JSON，一份配置对应一个批次。`batch` 决定所有产出文件名的前缀。

## 顶层

| 字段 | 必填 | 说明 |
|---|---|---|
| `batch` | ✅ | 批次代号，只用作文件名前缀（如 `20261026` → `20261026_run.json`） |
| `group` | ✅ | **运营组**，如「运营X组」。决定回填哪张投稿记录表（查 `assets/groups.json`）。必须开工前问使用者 |
| `brand` | ✅ | **品牌**。投稿记录必填维度，必须开工前问使用者 |
| `project` | ✅ | **项目**。投稿记录必填维度，必须开工前问使用者 |
| `outDir` | ✅ | 所有产出的落盘目录。**别指向会被清理的临时目录**，`run.json` 是续跑依据 |
| `sources` | ✅ | 素材来源数组，见下 |
| `job` | ✅ | 投稿参数，见下 |
| `limitMB` | | 单文件大小上限，默认 `600`；超限在 `plan` 阶段直接拦 |
| `titles` | ✅ | `文件名（含扩展名） → 标题`。文件名必须**完整带扩展名**，全角/半角空格要与实际一致。
|  |  | 不用手写：`bili_publish.py titles` 导出 CSV/TSV 填完再 `--import` 回来（会保留配置其他键）。 |
| `record` | | 投稿记录导出设置，见下 |
| `tdocs` | | 腾讯文档目标，见下 |
| `credentials` | | 三连凭据路径，默认 `%LOCALAPPDATA%\bilibili-sanlian-ads\credentials.json` |

## `sources[]`

| 字段 | 必填 | 说明 |
|---|---|---|
| `dir` | ✅ | 本地路径或 UNC（`\\\\主机\\共享\\...`）。路径不存在会直接报错，不会静默跳过 |
| `exts` | | 收哪些扩展名，默认 `[".mp4"]`，大小写不敏感 |
| `recursive` | | 是否递归子目录，默认 `false` |

同一个文件被多个 `sources` 覆盖时只收一次（按绝对路径去重）。

## `job`

| 字段 | 说明 |
|---|---|
| `accountId` | 三连广告账户 ID（不是 MID） |
| `mid` | 目标 UP 的 MID。脚本会调 `enterprise/mid` 实时校验，必须是该账户**已授权**的 UP |
| `categoryOne` / `categoryTwo` | B站分区一/二级 ID |
| `tags` | 稿件标签数组 |
| `maxPollMinutes` | 审核轮询上限，默认 90。平台拥堵时单条可能要 10–40 分钟，别设太小 |
| `pollIntervalSeconds` | 轮询间隔，默认 20 |

## `record`

| 字段 | 说明 |
|---|---|
| `columns` | 导出哪些列，默认 `[投稿时间, bvid, 原始文件名称, 品牌, 项目]`，顺序即表头顺序 |
| `timeFormat` | 时间格式，默认 `%Y-%m-%d %H:%M:%S`（东八区） |
| `tdocsStartRow` | 腾讯文档第一条数据行（表头占第 1 行时填 `2`）。不填则**不生成**腾讯文档载荷，只出 CSV |

可选列（`columns` 里想加就加）：

| 列名 | 内容 |
|---|---|
| `运营组` | 即 `group` |
| `标题` | 稿件标题 |
| `批次` | 即 `batch` |
| `大小MB` | 文件大小（1 位小数） |
| `审核状态` | 平台返回的状态文案，如「审核通过」 |
| `账号MID` | 投稿所用 MID |

## `tdocs`

| 字段 | 说明 |
|---|---|
| `url` | 分享链接，含 `?tab=xxxx`（tab 就是子表 ID） |
| `fileId` | 链接里 `/sheet/<fileId>` 那一段 |
| `tab` | `?tab=` 后面那一段，对应 MCP 的 `tab` / `sheet_id` 参数 |

## 关于 `投稿时间`

取 `run.json` 里每条的 `uploaded_at`（文件上传成功的时刻），转成东八区按 `timeFormat` 格式化。
如果业务要的是「审核通过时刻」，平台没给单条完成时间，只能用批次级 `completed_at` 或自己记账——不要拿 `uploaded_at` 冒充。
